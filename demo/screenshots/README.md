# Screenshot Captures Guide

Once the application is running locally at `http://127.0.0.1:8000/`, capture the following 3 high-resolution screenshots and save them in this folder:

1. **`01-dashboard.png`**:
   - Capture the main Dashboard tab showing the top KPI summary cards (Total Vessels, Vessels at Risk, Congested Berths, Avg Waiting Time, Crane Utilisation), the Berth Occupancy & Congestion Risk bars, Active Disruptions panel, and High Priority Vessel Queue.
2. **`02-vessel-analysis.png`**:
   - Capture the Vessel Analysis tab displaying the vessel telematic directory table with risk badges, priorities, assigned berths, and estimated waiting times.
3. **`03-operations-plan.png`**:
   - Capture the 72-Hour Ops Plan tab highlighting the shift supervisor operational timeline, recommended supervisor changes, and expected queue reduction impact summary.
